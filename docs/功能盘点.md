## 4. 预算与约束

- 启动参数：DarwinBoot 上限 1000 字节；D 包 888 字节；删掉重复的 `pagani-gpu-status=2` 后约 868 字节，余约 132 字节。常用开关字节数（含前导空格，今晚按 D 包原文核算）：`pagani-battery=1` 17、`pagani-adsp=1` 14、`pagani-adsp-stop=3` 19、`pagani-speaker=1` 17、`pagani-speaker-stop=4` 22、`pagani-audio-tone=1` 20、`pagani-haptics=2` 17、`pagani-haptics-ios=1` 21、`pagani-sensors=3` 17、`pagani-torch=2` 15、`pagani-rtc=1` 13、`pagani-aks-wrap=1` 18、`pagani-jetsam-floor=64` 23、`pagani-diag=1 sheng-no-lc=1` 28。单变量镜像放得下，叠加超过约 6 个开关就会超。
- 载荷：FAT 192 MiB、上限 95%；07:47 内核（127 MB）+ 新种子后只剩约 8.2 MB。新驱动会让内核略增；Wi‑Fi 固件放进种子大概率放不下，要就地读分区，或另议加大 `[payload]`（要先核实 fastboot boot 的镜像上限）。
- 日志：32 KiB 事件环只留开机约 56 s 以后的 exec/exit【评审补充：按 `RamoopsLog.h` 第 15–16 行，逐进程的 exec/exit 在约 28 KiB 的 console 环；32 KiB 事件环装的是 U、X、J 与状态行】；用户长按复位零翻转，PSCI/看门狗复位掉位（A 包只有 109/382 条校验通过）；同一进程 10 s 内只记一次 X 回溯。
- Data：每次开机全新，设置、密码、照片都不保留。
- 【评审补充】事件环：更准确地说，逐进程的 exec/exit 在约 28 KiB 的 console 环里；32 KiB 的事件环装的是驱动的 U 行、崩溃回溯（X）、卡顿（J）、状态行（`RamoopsLog.h` 第 15–16 行）。今晚每加一个分阶段驱动或诊断块，开机阶段行与崩溃回溯能留住的时间就更短，见 2.9“日志事件环容量”。
- 【评审补充】内存：XNU 只拿到 6 GiB（`xnu ram=0x8c007c000+0x180000000`），2 GiB 的 Data 内存盘按页分配在同一块内存里；Data 越满，App 可用内存越少，见 2.8 两行。
- 【评审补充】启动参数：Wi‑Fi 若靠内核自动加入，网络名与密码进启动参数会吃掉余量的大半，且明文进镜像。

## 6. 诚实说明：今晚做不完与永远做不到的

- 今晚一样都没有上机。B 级项目第一次上机就可能失败，“完美”今晚做不到；早上要按第 5 节逐级打开、逐项修。
- ADSP 从没在这台手机上跑过，而声音、充电控制、传感器都在它后面；如果 PAS 认证、SoCCP 依赖或 GLINK 握手卡住，这三类功能会一起停在原地。
- 声音即使内核链路全通，iOS 出声还要 audio2 把路由三道关口打通；麦克风再要 WCD939x 与 VA SoundWire，按声音组估计内核测试音 1–2 周、iOS 出声再 1–2 周、麦克风再 2–4 周（含多轮上机）。
- 传感器数据要 ADSP + SSC 协议 + 给 DSP 读配置的文件服务；屏下光感不做屏幕补偿只能在暗屏时给粗略值；计步与抬起唤醒在 iOS 里由运动协处理器算，AP 侧能否替代未证实。
- Wi‑Fi 能连网是多周：peach 不在 ath12k 支持列表、MSI 走 ITS 只能轮询、固件在 erofs 的 vendor 里且载荷只剩约 8 MB；连上之后还要钥匙串（记住密码）与 wifid 的设备树门。
- 这块硬件或这套系统上做不到（D）：蜂窝信号、电话、短信、蜂窝数据（CommCenter 要苹果基带协议与激活）；卫星定位（gpsd 不认高通基带里的 GNSS）；NFC 与 Apple Pay（Stockholm + SEP + 苹果安全元件）；Touch ID 与 Face ID（比对在 SEP，指纹 SPI 归 TZ）；苹果原生相机（`AppleH*CamIn` + ISP 固件）；App Store 第三方应用（只允许平台代码、没有 FairPlayIOKit）；“嘿 Siri”（AOP）；隔空投送、接力、个人热点、Apple Watch 配对；UWB（无硬件）；红外（iOS 无 API）；气压计（大概率无硬件）；80 W 快充（OPLUS 私有策略，不做）。
- 手电筒能点亮（B），但 iOS 的手电筒按钮挂在相机栈上；没有相机时只有测试开关，系统按钮是 C–D。
- 钥匙串的软件钥匙包不安全、每次开机失效；锁屏密码与数据保护（C）不在今晚范围。
- 持久存储要往手机 UFS 写，必须用户同意；今晚不做。Data 每次开机全新。
- 时间：没有网络与偏移时，RTC 方案只能给出“构建时刻下限”，时分会不准。
- 6+2 异构调度要换 AMP 内核配置，原作者多簇出过票锁 panic，不能用启动参数关掉，今晚不做；系统挂起（真正睡眠）同样是多周。
- 预算：启动参数余约 132 字节、载荷余约 8 MB、事件环只留 56 s 以后；这三样决定早上每张镜像只能加少量开关。
- 【评审补充】iOS 的关机与重启现在是坏的（2.4）：早上测试时不要点“关机”，复位一律用长按。
- 【评审补充】iPhone 专属的计算器、指南针、电话、钱包、Watch、日记在 iPad 根卷上根本没有，要从 iPhone 固件取，得先征得用户同意下载。
- 【评审补充】对中文用户，候选词为空就是打不出汉字；这条在 sysfix ④ 修好之前，“键盘能用”只对英文成立。
